# Claude AI Engineer Roadmap

A complete 15-stage learning path to master Claude — from AI fundamentals to building production-grade AI applications.

> **How to use this roadmap:** Each stage builds on the last. Spend 3–7 days per stage. Finish each with the listed mini-project before moving on. By Stage 15 you will have a portfolio of real Claude-powered tools.

---

## Prerequisites

- A Claude account (free is fine; Pro unlocks heavier use)
- Basic computer literacy
- For Stage 7+ : terminal familiarity, Node.js or Python
- For Stage 12+: ability to call an HTTP API

## How to track progress

- Every stage has a **Checklist** section. Tick boxes off as you go.
- Every stage ends with a **Capstone Exercise**. Don't skip it.
- Keep a `progress.md` file at the root and log what you built each week.

## Recommended pace

- **Fast (focused full-time):** ~6 weeks
- **Part-time evenings + weekends:** ~3 months
- **Casual hobbyist:** ~6 months

Don't rush. Stages 3, 4, 7, and 12 are the load-bearing ones — most engineers I've seen plateau because they skipped depth on prompting and the API.

---

## What you'll be able to do after Stage 15

- Write production prompts that survive edge cases
- Build a Claude-powered SaaS feature from scratch
- Integrate Claude with your existing tools (Slack, Notion, Linear, GitHub)
- Run a multi-agent system with tool use and MCP
- Deploy, monitor, and cost-control a real Claude workload
- Pass a Claude-focused AI engineering technical interview

Good luck. Start at [Stage 1](./stage-01-ai-basics/).
